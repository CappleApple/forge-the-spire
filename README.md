# Forge the Spire

Forge the Spire is an early-stage Slay the Spire 2 mod project focused on adding more build-crafting progression to the game.

## Status

This repository is currently a project placeholder. There is no installable build or gameplay implementation here yet.

The README is intentionally short until the mechanics and modding API work are far enough along to document accurately.
